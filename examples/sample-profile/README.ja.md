# Profile Signal — サンプルProfile

このディレクトリの [`README.md`](./README.md) は、Profile Signal導入後のGitHub Profile README表示を確認するための**固定サンプル**です。

- 数値・Repository名・時刻はすべてドキュメント用の架空データです。
- Private Repositoryや個人データは含みません。
- 実際の導入時はPublic GitHub Activityから同じ構造のWidgetが生成されます。
- QiitaやREADME用のスクリーンショットは、`README.md` をGitHub上でレンダリングした画面を利用できます。
