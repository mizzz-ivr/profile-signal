# Profile Signal v0.3.0

Profile Signalの開発・配布Source of Truthを、GitHub Profile Repository `mizzz-ivr/mizzz-ivr` から専用OSS Repository **`mizzz-ivr/profile-signal`** へ分離したReleaseです。

## 主な変更

### Standalone OSS Repositoryへ移行

`v0.3.0` 以降は以下を `mizzz-ivr/profile-signal` で管理します。

- Profile Signal runtime
- Release ZIP builder
- tests / CI
- Release Notes
- GitHub Releases
- GitHub Wiki
- Preset Registry
- 配布用config / workflow template

`mizzz-ivr/mizzz-ivr` は今後、Profile Signalを実際に利用する **Live Demo / Dogfooding環境** として扱います。

### English / 日本語ドキュメント

READMEとWikiを英語・日本語の2言語構成にしました。

- `README.md` — English
- `README.ja.md` — 日本語
- Wiki — Englishをdefault、`-ja`ページで日本語版を提供

Wiki Sourceは `docs/wiki/` で管理し、main更新後にGitHub Wikiへ自動同期します。

### MIT LicenseをRepository全体へ明確化

standalone Repositoryはroot `LICENSE` をSource of Truthとし、Profile Signalのruntime・配布ツール・tests・docsをMIT Licenseで公開します。

Release ZIP内にも `.profile-signal/LICENSE` を含めます。

### 8 Presetを継続

以下のPresetを同梱します。

- `minimal`
- `standard`
- `full`
- `terminal`
- `compact`
- `developer`
- `activity`
- `oss`

Preset定義は `.profile-signal/presets/*.yml` に分離されており、今後も既存Presetの意味を壊さず新Presetを追加していく方針です。

### ACTIVITY STREAMを30分更新へ分離

これまでプロフィール全体を3時間ごとに更新していたため、`ACTIVITY STREAM // Latest public signals` の鮮度が役割に対して低い状態でした。

v0.3.0では更新を2系統へ分離します。

- `profile-signal.yml` — 3時間ごとのフル更新
- `profile-signal-stream.yml` — 30分ごとの軽量Latest signals更新

30分Workflowは次だけを更新します。

- LIVE SIGNAL
- CURRENT FOCUS
- ACTIVITY STREAM

TODAY、DEV PULSE、CI / Health、Weekly / Monthly、Achievementsなどの重い集計は3時間Workflowに残します。Latest signals側は既存の重いstateを保持し、表示内容に変化が無ければcommitしません。

GitHub Public Events自体に反映遅延が発生する可能性があるため、ACTIVITY STREAMはリアルタイム保証ではなく「取得できた最新の公開Signal」として扱います。

## 導入

1. このRepositoryのAssetsから `profile-signal-v0.3.0.zip` をダウンロードします。
2. 自分のGitHub Profile Repository (`<username>/<username>`) のrootへ展開します。
3. `.github/profile-signal.yml` のusernameを変更します。
4. commit / pushします。
5. **Actions → Profile Signal → Run workflow** を1回実行します。

標準構成はpublic-onlyで、PATやAPI Keyは不要です。

## v0.1.0 / v0.2.0について

`v0.3.0` 以降のRelease / Wiki / Issue / Source codeはこのstandalone RepositoryをSource of Truthとします。
