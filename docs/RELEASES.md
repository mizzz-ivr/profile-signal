# Releases

Profile Signal releases are published from `mizzz-ivr/profile-signal` starting with v0.3.0.

Release packages are self-contained ZIP archives intended to be extracted into a GitHub Profile Repository.

Historical v0.1.0 and v0.2.0 release notes are kept here for continuity, but those versions were originally published from `mizzz-ivr/mizzz-ivr` before the standalone OSS migration.

For the latest package and notes, use this repository's GitHub Releases page.
