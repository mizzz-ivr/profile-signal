# Presets

[English](Presets) | [日本語](Presets-ja)

Built-in presets: `minimal`, `standard`, `full`, `terminal`, `compact`, `developer`, `activity`, `oss`.

Presets are YAML files under `.profile-signal/presets/`. Existing preset meanings are kept backward-compatible; new layouts should normally use a new preset ID. User widget overrides always take precedence.
