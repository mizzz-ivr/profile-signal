# Installation

[English](Installation) | [日本語](Installation-ja)

1. Download `profile-signal-vX.Y.Z.zip` from [Releases](https://github.com/mizzz-ivr/profile-signal/releases).
2. Extract it into `<username>/<username>`.
3. Set `profile.username` in `.github/profile-signal.yml`.
4. Commit and push.
5. Run **Actions → Profile Signal → Run workflow**.

Installed files include `.profile-signal/`, the config, the workflow, install notes, and a version marker. The archive does not overwrite your README.

To upgrade, replace `.profile-signal/` with the runtime from the new release and review the diff before committing.
